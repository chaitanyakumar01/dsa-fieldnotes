# DSA Fieldnotes

An interactive Striver A2Z study planner with a guided session calendar, official module totals, and a LeetCode practice pool.

## Run locally

Open `index.html` in a browser. Progress is stored in that browser's local storage.

## Scope

The official A2Z sheet currently lists 20 modules and 495 problems. The planner has 126 guided study sessions for a five-month study rhythm; those counts are different. The linked official sheet is the source for the full problem list.
